# Web 管理控制台功能规格说明书

> **模块归属**：O-Maid Cloud Server Dashboard (管理端)  
> **设计定位**：云端共享中枢、规则审核与生命周期管理、账号权限体系、服务状态监控  
> **访问入口**：启动后端服务后，直接在浏览器中打开根路径 `http://localhost:<端口>/`

---

## 1. 界面框架与视觉规范

- **架构形式**：单页应用 (SPA) 架构，纯原生 HTML5 + CSS3 + 原生 JavaScript 构建，无需额外前端构建工具。
- **设计风格**：深色高质感玻璃拟态风格（Dark Glassmorphism），主色调为科技深蓝与优雅亮紫（`#6366f1`）。
- **布局划分**：
  - **左侧全局侧边栏**：展示品牌 Logo（O-Maid Cloud v1.1）及五大核心功能模块导航栏。
  - **顶部状态栏**：当前所在模块标题、快速返回入口与运行状态指示。
  - **右侧主体工作区**：根据左侧导航动态切换的内容容器，各模块平滑切换。

---

## 2. 平台概览看板 (Dashboard Overview)

### 2.1 统计指标卡 (Metric Cards)
提供 4 个卡片，用于宏观把控平台核心运行规模：
1. **创作者总数**：已注册并激活的独立用户总数（人）。
2. **引导任务总数**：全平台目前已发布且处于有效状态的引导流程总数（个）。
3. **悬停提示总数**：全平台已发布的悬停提示总数（个）。
4. **全网累计下载**：所有用户在插件端点击「下载」克隆规则的累计总次数（人次）。

### 2.2 实时动态信息流 (Recent Activity Timeline)
- 时间线模式按时间倒序展示最新发布的引导任务与悬停提示。
- 每条动态标注：规则名称、所属类型（引导任务/悬停提示）、发布作者、发布时间戳。

---

## 3. 引导任务管理 (Guides Management)

负责管理全网用户上传的 Guided Tours 引导流程，支持检索、查看详情、录入与下架。

### 3.1 搜索与过滤
- 提供实时搜索框，支持同时按**任务名称**、**生效域名**或**作者用户名**进行即时模糊过滤，无需重复回车。

### 3.2 全景数据表格
| 字段列 | 说明 |
| :--- | :--- |
| **任务名称** | 引导流程的标题。 |
| **生效域名** | 规则所绑定的目标网址或域名标签（如 `www.google.com`）。 |
| **步骤数** | 该任务内部包含的引导步骤总数（如 `3 步`），点击可展开详情。 |
| **发布作者** | 创建并上传该任务的用户名。 |
| **下载量** | 全网客户端已下载克隆的次数。 |
| **发布时间** | 上传时间，格式化展示为 `YYYY/MM/DD HH:mm`。 |
| **操作列** | 提供「步骤详情」与「删除下架」两大操作按钮。 |

### 3.3 步骤详情弹窗 (Step Details Modal)
- 点击任务行的「步骤详情」按钮唤出全屏居中模态框。
- 完整按序展示该引导任务的所有内部步骤：
  - 步骤序号（如 `步骤 1`）。
  - 该步骤的引导文案内容。
  - 该步骤所绑定的具体目标元素 CSS 选择器（如 `#search-input`）。

### 3.4 任务删除 (Delete Action)
- 点击操作列的垃圾桶图标触发二次确认弹窗。
- 确认后调用 `DELETE /api/guides/:id`，从数据库中物理删除该记录，并即时刷新前端列表。

### 3.5 Web 端创建新任务 (Create Modal)
- 支持管理员直接在 Web 控制台录入测试或官方任务，支持动态追加多个步骤。

## 4. 悬停提示管理 (Hover Hints Management)

负责管理全网用户上传的 Hover Hints 屏幕提示规则。

### 4.1 检索与展示
- 支持按提示文案、目标域名或选择器进行实时检索。
- 全景表格字段包括：提示文案摘要、适用域名、绑定的 CSS 选择器、发布作者、**下载量（🔥 次数徽章）**、发布时间。
- 与引导任务管理保持一致，直观体现不同悬停提示在全网被用户下载/使用的热度。

### 4.2 提示删除与录入
- **删除下架**：确认后调用 `DELETE /api/hints/:id`，从服务端彻底下架。
- **录入新提示**：提供模态框，支持在 Web 端录入文案、域名与选择器。

---

## 5. 注册用户账号管理 (User Management)

实现完整的用户生命周期管理闭环，解决账号录入、密码找回与违规注销问题。

### 5.1 注册新用户 (Register New User)
- 控制台顶部常驻 **`[+ 注册新用户]`** 按钮。
- 点击唤出注册模态框，输入用户名和初始密码，直接完成新账号创建，并支持在插件端直接使用。

### 5.2 用户列表全景表格
| 字段列 | 说明 |
| :--- | :--- |
| **用户 ID** | 数据库自增唯一标识（如 `#1`）。 |
| **用户名** | 账号名称。 |
| **角色** | 账号角色标签（默认为 `创作者 (Creator)`）。 |
| **注册时间** | 账户创建时间。 |
| **累计作品数** | 该用户已发布的任务与提示累计总数。 |
| **操作列** | 提供「重置密码」与「删除用户」两大管理按钮。 |

### 5.3 重置密码 (Reset Password)
- 点击操作列的「重置密码」按钮唤出修改弹窗。
- 输入新密码，后端通过 `bcrypt` 重新计算哈希并更新数据库，确保安全性。

### 5.4 注销与删除用户 (Delete User)
- 点击操作列的删除图标，弹出确认警告。
- 确认后调用 `DELETE /api/auth/users/:id`：
  - 彻底注销该用户账号；
  - 自动解除该用户关联作品的归属或级联清理，防止数据孤岛与外键约束报错。

## 6. 系统监控与 API 调试控制台 (System & API Specs)

### 6.1 服务端健康监控 (Health Monitor)
- **Node.js 运行时版本**：如 `v18.x` / `v20.x`。
- **服务持续运行时间 (Uptime)**：实时计算已运行的天、时、分、秒。
- **内存占用监控 (Memory)**：实时监控 Node 进程的常驻内存（RSS）与堆内存（Heap Used）。
- **数据库状态**：显示 SQLite 数据库连接与表初始化就绪状态。

### 6.2 开放 API 接口文档 (API Reference)
内置完整的 RESTful API 文档，列明请求路径、方法（GET/POST/DELETE）、请求头、请求体格式及响应示例，便于开发者或插件端随时排查与调试。
