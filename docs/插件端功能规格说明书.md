# 浏览器插件端功能规格说明书

> **正式名称**：O-Maid 页面智能助手 (O-Maid Page Smart Assistant)  
> **设计定位**：网页元素智能标注、悬停提示与自动化业务流程引导助手  
> **视觉标识**：高亮指示引导风（发光光棒高亮网页文档，科技蓝与琥珀金光芒）  
> **模块归属**：O-Maid Chrome Extension (浏览器客户端)

---

## 1. 面板容器与窗口交互系统

### 1.1 侧边栏挂载与停靠
- **Shadow DOM 隔离**：面板通过宿主元素 `#o-maid-ui-host` 注入网页，内部挂载独立 Shadow DOM，确保样式与宿主网页完全隔离，互不干扰。
- **悬浮展开手柄 (Collapse Tab)**：
  - 侧边栏折叠后，页面右侧常驻精致微型标签 `📋`。
  - 点击悬浮手柄即可平滑滑出侧边栏。
- **宽度拖拽调整 (Resize Handle)**：
  - 面板左边缘提供 10px 拖拽区域，鼠标悬停变为 `col-resize` 光标。
  - 支持在 `280px` 至 `600px` 之间自由拖动调节宽度。
  - 用户设定的宽度自动持久化保存，下次打开自动复用。
- **折叠与关闭**：
  - 点击 Header 上的 **`◀`** 按钮：面板快速滑向右侧边缘折叠，展示手柄。
  - 点击 Header 上的 **`✕`** 按钮：面板彻底关闭退出渲染。

## 3. 主界面与分段导航

主界面采用现代一体化胶囊分段选择器（Segmented Control），实现「本地库」与「云端发现」的丝滑切换：

### 3.1 本地规则库 (本地库 Tab)
用于查看、管理和运行当前保存在浏览器本地的所有规则。

#### 规则展示策略（默认当前网页匹配 + 全量规则切换）
- **默认模式（当前网页精准匹配）**：
  - 打开本地库时，**默认仅展示属于当前网页的提示与引导任务**，界面保持极度纯粹、精准适配当前页面业务。
- **全量切换能力（查看全部本地规则）**：
  - 顶部常驻 **`范围: 当前网页 [查看全部规则]`** 切换按钮；
  - 点击“查看全部规则”可展开本地保存的所有网站任务，非当前网页的任务前附带域名微标（如 `[google.com]`），引导任务保留「跳转并开始任务」能力。
- **云端同步数据刷新与冲突仲裁机制 (Sync Refresh & Conflict Resolution)**：
  - 范围操作栏右侧常驻 **`[🔄 刷新]`** 按钮（单行紧凑排版，防折行）；
  - **所有权写保护机制**：
    - 已从云端下载的规则（`isDownloaded: true`）受原作者主权保护；
    - 任何下载者在本地所做的修改，**坚决不能直接同步/覆盖回原作者的云端规则**；若尝试发布，系统拦截并提示只读或引导另存为个人专属新规则。
  - **刷新时的冲突检测与仲裁**：
    - 点击「🔄 刷新」时，自动检测本地规则是否已被二次修改（基于基线指纹 `baseSignature` 计算 `isLocallyModified`）；
    - **无改动规则**：静默就地升级至云端最新版本；
    - **本地已改动且云端有更新的规则**：
      - 严禁静默覆盖！在词条旁打上显著橙色徽章：`⚠️ 本地已修改 (云端有更新)`；
      - 弹出冲突仲裁弹窗，向用户列出冲突项详情，由用户明确决断：
        - **【覆盖本地】**：放弃本地改动，彻底同步为原作者最新云端版本；
        - **【保留本地】**：维持当前本地定制成果，不予覆写。
    - 详见专题规范文档：[规则权限与冲突同步机制规范.md](./规则权限与冲突同步机制规范.md)。
- **空数据引导**：当当前网页没有配置规则时，友好提示：*当前网页暂无本地规则，[点击查看全部规则 >>]*。

#### 分组一：引导任务 (Guided Tours)
- **手风琴交互**：点击分组标题折叠或展开任务列表。
- **快捷创建按钮**：标题右侧常驻 **`[+ 新建]`** 单行胶囊按钮，样式为现代柔光浅蓝（`background: rgba(13, 110, 253, 0.08); color: #0d6efd`），附带 `title="一键新建引导任务"` 提示。
- **任务卡片信息**：展示任务名称、步骤总数、触发方式（手动/自动）。
- **任务卡片操作组（统一极简微卡片设计 + 100% 悬停提示覆盖）**：
  - 尺寸统一定制为 `26px × 26px` 圆角微卡片，浅色极简质感，悬停微升起；
  - **`▶` 播放**：绿色高亮态，Tooltip 提示 `开始引导任务`；
  - **`↺` 重置**：柔和灰态，Tooltip 提示 `重置完成状态`；
  - **`☁️/🌐` 云端同步**：依云端状态差异化呈现，全量配备状态 Tooltip；
  - **`✏️` 编辑**：蓝色悬停态，Tooltip 提示 `编辑此任务`；
  - **`🗑️` 删除**：红色悬停态，Tooltip 提示 `删除此任务`。

#### 分组二：悬停提示 (Hover Hints)
- **手风琴交互**：点击分组标题折叠或展开提示列表。
- **快捷创建按钮**：标题右侧常驻 **`[+ 新建]`** 胶囊按钮，附带 `title="一键新建悬停提示"` 提示。
- **提示卡片信息**：展示提示文案摘要、绑定的目标元素 CSS 选择器。
- **提示卡片操作组（统一极简微卡片设计 + 100% 悬停提示覆盖）**：
  - **`☁️/🌐` 云端同步**：依云端状态差异化呈现，配备状态 Tooltip；
  - **`✏️` 编辑**：蓝色悬停态，Tooltip 提示 `编辑此提示`；
  - **`🗑️` 删除**：红色悬停态，Tooltip 提示 `删除此提示`。

### 3.2 云端共享大厅 (云端发现 Tab)
用于从服务器拉取由社区或团队成员分享的公开发布规则。

#### 范围切换机制
- **当前网站 (智能精准匹配)**：
  - 默认模式。自动提取当前宿主网页的域名（例如 `baidu.com` 或 `localhost`），精准向服务器拉取仅适应该网站的规则。
- **全网大厅 (跨域名全量浏览)**：
  - 点击 **`[查看全网大厅]`** 切换。跨域名拉取所有公开发布的规则。
  - 列表项前面均显式展示适用的域名徽章（如 `[www.google.com]`），方便跨站查阅与下载。

#### 列表项与下载
- 展示任务名称/文案、适用域名徽章、发布作者、全网累计下载人次。
- **`⬇️` 一键下载**：点击后将该云端规则无损克隆写入本地 `chrome.storage.local`，并在本地库中立即可用；同时通知后端下载计数器自增 1。
- **手动刷新**：提供 **`[刷新云端数据]`** 按钮，支持随时手动同步最新列表。

## 4. 录入编排与屏幕点选系统

### 4.1 悬停提示录入与展示规范
1. **录入流程**：
   - 点击 `+ 新建提示` 或在选择卡中选择「悬停提示」。
   - 输入期望在鼠标悬停时显示的提示文本。
   - 点击 **`[重选]`** 激活全屏屏幕拾取器，鼠标在网页上悬浮时生成高亮框，左键点击目标元素完成绑定。
   - 点击 **`[保存]`**，规则生效并立即激活监听。
2. **目标元素悬停高亮展示规范**：
   - 当用户在网页上将鼠标悬停在配置了提示的目标元素上时：
     - **气泡展示**：自适应弹出半透明毛玻璃悬停提示卡片，展示说明文案；
     - **目标元素高亮 (Target Highlight)**：**目标元素本身同步施加醒目的蓝色柔光外描边高亮（`outline: 2px solid #0d6efd` + `box-shadow`）**，让用户一眼明确当前提示具体指向页面的哪个元素或区域；
   - 当鼠标移出该目标元素时，高亮边框与提示气泡同时平滑销毁。

### 4.2 引导任务编排流程
1. 点击 `+ 新建引导` 或在选择卡中选择「引导任务」。
2. 输入引导任务名称（如“新手发帖向导”）。
3. 选择触发方式（手动点击播放 / 打开页面自动触发）。
4. 点击 **`[+ 添加步骤]`** 录入具体步骤：
   - 填写该步骤的提示说明。
   - 点击 **`[重选]`** 拾取页面上对应的高亮目标元素。
   - 点击 **`[保存步骤]`**，步骤追加至步骤列表。
5. 在步骤列表中可点击步骤进行二次编辑或删除，编排完成后点击 **`[保存引导]`**。

### 4.3 屏幕元素拾取器 (Element Selector)
- **智能选择器算法**：优先提取元素的有效唯一 `ID`，次选语义化复合 `Class`，兜底采用结构化 `nth-child` 路径，保证选择器的高稳定性。
- **Shadow DOM 穿透隔离防护**：
  - 严格通过 `e.composedPath()` 检测事件来源，绝对排除宿主 `#o-maid-ui-host` 及其内部的面板元素，防止面板自身的点击（如重选、取消、输入框）被错误捕获或拦截。
- **全局视觉提示浮条 (Selection Guide Banner)**：
  - 激活选择模式时，屏幕正上方展示轻量半透明提示条：`🎯 正在选择元素：请在页面上直接点击目标元素（按 ESC 键取消）`；
  - 元素被点击选中后，提示条自动隐退；
- **交互生命周期保障**：
  - 支持键盘 **`ESC`** 键随时安全退出选择模式；
  - 用户在插件面板点击「取消」、「关闭面板」、「保存」或切换视图时，**全局自动调用 `stopSelectionMode()`** 彻底清理事件与高亮，杜绝状态锁死。
  - 点击「重选」按钮时，允许直接重置并重新激活选择器。

## 6. 全局存储与多标签页漫游机制

- **存储底座**：彻底废弃与当前宿主网页 Origin 强绑定的 `localStorage`，全面采用 Chrome 扩展级全局存储 **`chrome.storage.local`**。
- **全局漫游效果**：
  - 用户在任一网页登录账号，所有已打开和未来打开的网页标签页**全部无感保持登录状态**。
  - 用户修改了后端 API 端口配置（如改用 `8632`），**全局各网页即时同步生效**。
- **跨页面实时联动与生命周期容灾 (BFCache 防护)**：
  - 监听 `chrome.storage.onChanged` 事件，当某个标签页触发了登录、退出或端口变更时，其他所有页面无需刷新，面板自动即时响应更新。
  - **BFCache (往返缓存) 异常防御**：
    当页面发生跳转或前进/后退被浏览器存入 BFCache 时，浏览器会强行切断扩展长连接（Port）。
    在 `background.js` 和 `communication.js` 的 `port.onDisconnect` 中**强制读取并消费 `chrome.runtime.lastError`**，安全清理已失效的 Port 引用，彻底杜绝出现 `Unchecked runtime.lastError: The page keeping the extension port is moved into back/forward cache` 红色报警。

## 7. 全局唯一标识算法与数据去重防重机制 (Unique ID & Deduplication)

因为引导任务与悬停提示是由各个用户在**浏览器本地独立配置生成**、然后再发布同步至云端服务，为了从根本上杜绝“不同用户本地生成产生冲突”、“同一作品重复上传下载产生冗余”等问题，建立严格的独特生成算法与去重规范：

### 7.1 全局唯一规则标识算法 (GURID 算法)
本地创建任何新规则（引导或提示）时，严禁使用脆弱的时间戳随机数（如 `Date.now()`），必须采用**「匿名设备指纹 / 账号标识 + 密码学强随机 UUID」**算法：
- **核心算法构成**：
  ```javascript
  // 规则前缀_设备或创作者标识_密码学强随机UUIDv4
  const ruleId = `om_${type}_${clientTag}_${crypto.randomUUID()}`;
  ```
- **面对未登录用户的解决方案 (免登录设备指纹)**：
  - **安装即签发**：插件初次运行激活时，自动在 `chrome.storage.local` 中持久化生成一个**永久唯一的匿名客户端设备指纹**：`anonymous_client_id: "anon_" + crypto.randomUUID()`；
  - **不登录时的 `clientTag`**：直接提取该匿名设备指纹的前 12 位（如 `anon_8f3a9c`）；
  - **登录后的 `clientTag`**：自动升级为当前账号的用户名哈希（如 `usr_test`）；
  - **128位密码学真随机 (CSPRNG)**：核心依赖底层浏览器提供的 `crypto.randomUUID()`，该算法具备 122 位独立真随机熵。
- **数学唯一性保障**：
  - 哪怕全球用户**全部不登录账号**，A 电脑与 B 电脑生成的 `ruleId` 碰撞概率也低于 $10^{-36}$（在全人类计算历史上绝对独一无二）！

### 7.2 脱离登录态的业务内容语义指纹 (Content Signature)
去重**绝不依赖用户是否登录**，因为业务内容本身具有天然的物理特征：
- **引导任务指纹**：
  `Signature(Tour) = Hash(domain + "|" + name + "|" + steps.map(s => s.selector + "@" + s.text).join(";"))`
- **悬停提示指纹**：
  `Signature(Hint) = Hash(domain + "|" + selector + "|" + text)`
- **去重原理**：
  无论用户是否登录，只要在同一个网站上对同一组元素录入了相同文案，计算出的 `Signature` 必定完全相同。系统据此便能 100% 精准识别重复项，执行就地合并更新！

### 7.3 智能去重与防重判定逻辑
1. **云端下载防重**：
   - 客户端从云端下载规则时，记录其原生的 `cloud_id` 与 `signature`；
   - 若本地已存在相同 `cloud_id` 或相同 `signature` 的任务：
     **执行「覆盖更新 (Update)」**，保持本地数据最新，界面提示 `本地已存在该内容，已自动同步更新为最新版！`，绝不重复生成双胞胎卡片。
2. **多用户同名隔离**：
   - 若 A 用户创建了《新手指南》，B 用户也创建了《新手指南》：
     由于各自的 `steps` 元素选择器不同（即 `signature` 不同），系统判定为**两个不同创作者的独立作品**，二者共存，互不干扰、互不覆盖。
3. **存量历史重复数据自动清洗**：
   - 本地库加载时，以 `signature` 为指纹进行安全扫描，若检测到此前因重复下载生成的完全相同副本，自动合并保留最新一条并静默回写持久化。
