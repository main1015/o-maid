# 系统接口与数据模型规范

> **适用范围**：O-Maid 后端服务（Express）、SQLite 数据库与客户端数据交互协议  
> **服务基础路径**：`http://localhost:<PORT>/api`

---

## 1. 数据库模型设计 (SQLite Schema)

服务使用本地 SQLite 数据库（`server/database.sqlite`），包含三张核心实体表：

### 1.1 `users` 用户表
存储注册用户的身份凭证与基础信息。
```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,          -- bcrypt 加密存储
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 1.2 `guides` 引导任务表
存储公开发布的页面导览流程。
```sql
CREATE TABLE IF NOT EXISTS guides (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    domain TEXT NOT NULL,            -- 适用域名 (如 www.google.com)
    name TEXT NOT NULL,              -- 任务标题
    steps TEXT NOT NULL,             -- JSON 序列化存储的步骤数组 [{text, selector}, ...]
    author_id INTEGER,               -- 关联 users.id (可为 NULL 兼容免登录或注销后保留)
    author_name TEXT,                -- 发布者用户名快照
    downloads INTEGER DEFAULT 0,     -- 累计下载次数
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(author_id) REFERENCES users(id) ON DELETE SET NULL
);
```

### 1.3 `hints` 悬停提示表
存储公开发布的页面元素悬停提示。
```sql
CREATE TABLE IF NOT EXISTS hints (
    id TEXT PRIMARY KEY,
    domain TEXT NOT NULL,            -- 适用域名
    url TEXT,                        -- 页面完整地址
    selector TEXT NOT NULL,          -- 目标元素的 CSS 选择器
    text TEXT NOT NULL,              -- 提示展示文案
    authorId INTEGER,                -- 关联 users.id
    downloads INTEGER DEFAULT 0,     -- 累计下载次数
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(authorId) REFERENCES users(id) ON DELETE SET NULL
);
```

## 2. 身份认证与安全机制 (Authentication)

- **密码加密**：用户注册或密码重置时，使用 `bcrypt.hash(password, 10)` 进行单向哈希加盐存储。
- **Token 机制**：基于 `jsonwebtoken` (JWT)。用户成功登录后，服务端签发有效期为 7 天的 JWT Token。
- **请求鉴权**：写操作（如从插件发布引导或提示）需在 HTTP Header 中携带：
  ```http
  Authorization: Bearer <JWT_TOKEN>
  ```
- **中间件校验**：通过 `server/middleware/auth.js` 解析 Token，未传或无效时拒绝请求并返回 401。

## 3. 全量 RESTful API 接口规范

### 3.1 账号与用户管理模块 (`/api/auth`)

#### 1. 用户注册
- **接口路径**：`POST /api/auth/register`
- **请求体**：
  ```json
  { "username": "test_user", "password": "password123" }
  ```
- **响应体**：
  ```json
  { "success": true, "message": "注册成功，请登录" }
  ```

#### 2. 用户登录
- **接口路径**：`POST /api/auth/login`
- **请求体**：
  ```json
  { "username": "test_user", "password": "password123" }
  ```
- **响应体**：
  ```json
  {
    "success": true,
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "username": "test_user"
  }
  ```

#### 3. 重置用户密码
- **接口路径**：`POST /api/auth/users/:id/reset-password`
- **请求体**：
  ```json
  { "newPassword": "new_password_888" }
  ```
- **响应体**：
  ```json
  { "success": true, "message": "密码修改成功" }
  ```

#### 4. 删除/注销用户
- **接口路径**：`DELETE /api/auth/users/:id`
- **响应体**：
  ```json
  { "success": true, "message": "用户及作品关联已成功清理" }
  ```

### 3.2 引导任务模块 (`/api/guides`)

#### 1. 按域名获取任务 (插件端精准拉取)
- **接口路径**：`GET /api/guides?domain=www.google.com`
- **响应体**：
  ```json
  {
    "success": true,
    "guides": [
      {
        "id": 1,
        "name": "谷歌搜索入门",
        "domain": "www.google.com",
        "steps": [
          { "text": "输入搜索关键词", "selector": "#APjFqb" },
          { "text": "点击搜索按钮", "selector": "input[name='btnK']" }
        ],
        "author": "test_user",
        "downloads": 5
      }
    ]
  }
  ```

#### 2. 获取全网所有任务 (全网大厅 / Web 控制台)
- **接口路径**：`GET /api/guides/all`
- **响应体**：返回数据库中所有已发布的任务列表数组。

#### 3. 发布/更新任务 (带原作者写保护)
- **接口路径**：`POST /api/guides`
- **请求头**：`Authorization: Bearer <TOKEN>` (必填，发布/更新必须登录)
- **写保护机制**：
  - 若携带已有 `id` 且数据库中已存在该记录，系统严格校验当前登录用户必须为该任务的原作者（`authorId == req.user.id`）或超级管理员；
  - 若非原作者（如下载者 B 尝试覆写原作者 A 的规则），服务端强行拦截并拒绝，返回 `403 Forbidden`。
- **请求体**：
  ```json
  {
    "id": "tour-1725432000000-xyz",
    "domain": "www.google.com",
    "name": "搜索引导",
    "steps": [ { "text": "...", "selector": "..." } ]
  }
  ```
- **成功响应**：`{ "success": true, "id": "tour-1725432000000-xyz" }`
- **越权失败响应**：`HTTP 403 Forbidden` -> `{ "error": "权限不足：您不是该规则的原作者，无法覆写云端原版规则" }`

#### 4. 下载计数自增
- **接口路径**：`POST /api/guides/:id/download`
- **响应体**：`{ "success": true, "downloads": 6 }`

#### 5. 删除任务
- **接口路径**：`DELETE /api/guides/:id`
- **响应体**：`{ "success": true, "message": "删除成功" }`

### 3.4 规则与云端同步刷新协议 (Sync Refresh Protocol)

详见专题技术规范文档：[规则权限与冲突同步机制规范.md](./规则权限与冲突同步机制规范.md)。

#### 1. 比对判定基准
- 插件遍历本地全部带有 `cloudId` 的规则。
- **基线语义指纹 (`baseSignature`)**：记录下载时的规则特征。
- **本地修改标记 (`isLocallyModified`)**：若用户在本地对下载规则的步骤、选择器或文案做了二次修改，自动置为 `true`。

#### 2. 刷新时的冲突仲裁 (Conflict Arbitration)
- **纯净更新 (Clean Update)**：若本地未被修改（`!isLocallyModified`），直接将云端最新快照覆写到本地（步骤/选择器/文案/下载量），保留本地主键 `id` 和创建时间不变。
- **冲突拦截 (Conflict Resolution)**：
  - 若本地已被修改（`isLocallyModified === true`）且云端原作者也发布了新版本：
  - 严禁静默覆盖！在侧边栏对应词条右侧打上 `⚠️ 本地已修改 (云端有更新)` 标签；
  - 弹出冲突确认窗口，交由用户决策：
    - **【覆盖本地】**：放弃本地改动，彻底同步为原作者最新云端版本；
    - **【保留本地】**：维持当前本地定制成果，不予覆写。

#### 3. 同步刷新业务逻辑
- **目标对象**：本地存储中所有已与云端关联的规则，判定标准为存在 `cloudId`（包含用户主动发布成功的作品 `isSynced: true` 与从云端大厅安装的作品 `isDownloaded: true`）。
- **执行流程**：
  1. 插件端扫描提取本地所有 `cloudId`；
  2. 请求服务端拉取对应云端实体的最新数据；
  3. **就地安全覆盖 (In-place Safe Update)**：
     - 保留本地的唯一持久化标识（本地主键 `id`、创建时间不变）；
     - 深度更新云端最新属性：任务步骤 `steps`、任务名称 `name`、提示文案 `text`、CSS 选择器 `selector`、最新作者 `author` 及云端下载量 `downloads`；
     - 保持本地同步标识 `isSynced: true`；
  4. **云端已下架处理**：若某条 `cloudId` 在云端已不存在（已被原作者或管理员彻底删除），将本地对应记录标记为 `isSynced: false`（脱钩解除同步），保留本地副本供用户继续使用。
  5. **操作反馈**：统计本次刷新的有效变动条数，向用户弹出成功提示。

## 4. 全局异常处理与容错规范

1. **404 兜底机制**：
   - 任何未匹配的 `/api/*` 请求，服务端**强制返回 JSON 格式**（禁止返回 Express 默认的 HTML 404 错误页）：
     ```json
     { "error": "Not Found", "message": "API 接口不存在" }
     ```
   - 彻底杜绝客户端解析 JSON 时触发 `Unexpected token '<', "<!DOCTYPE "... is not valid JSON` 异常。
2. **连接超时与网络诊断**：
   - 客户端在 `fetch` 请求失败时，必须捕获网络异常并明确提示当前连接的 API 端口（如 `无法连接服务器 (http://localhost:8632/api)`），引导用户自检。
