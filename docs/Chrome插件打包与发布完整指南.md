# Chrome 插件打包与发布完整指南

本文档作为 O-Maid（页面元素助手）插件打包、版本构建与发布的标准化作业指导书（SOP），涵盖**企业/内部私有分发**与**Chrome 网上应用店官方公开发布**两种完整路径。

---

## 一、发布方式选型与对比

| 维度 | 途径一：企业 / 内部私有分发（推荐） | 途径二：Chrome Web Store 官方公开发布 |
| :--- | :--- | :--- |
| **适用场景** | 团队内部、公司内网、企业 OA 办公系统使用 | 面向全球互联网公众用户 |
| **审核周期** | **零审核**，即打即用，随时分发 | 需 Google 官方审核（通常 1 ~ 3 个工作日） |
| **费用成本** | **完全免费** | 需向 Google 支付一次性 **$5 美元** 开发者注册费 |
| **安装方式** | 拖拽 `.crx` 文件安装，或企业域策略静默推送 | 应用商店页面点击“添加至 Chrome”一键安装 |
| **更新方式** | 重新分发 `.crx` 或通过自建 Update URL 更新 | 商店后台更新版本后，客户端浏览器自动静默拉取更新 |

## 二、途径一：企业 / 内部私有分发实操

### 2.1 方式 A：打包为 `.crx` 文件直接分发（最常用）

#### 步骤 1：准备打包目录
确保 `/home/wy/code/chrome/o-maid/extension` 目录下所有文件已就绪，且已更新 `manifest.json` 中的 `version`（如从 `1.0` 升级为 `1.1`）。

#### 步骤 2：使用 Chrome 自带工具打包
1. 在 Chrome 浏览器地址栏输入并打开：`chrome://extensions/`；
2. 开启右上角的 **「开发者模式」** 开关；
3. 点击左上角弹出的 **「打包扩展程序 (Pack extension)」** 按钮；
4. 填写配置项：
   - **扩展程序根目录**：选择你的 `extension` 目录（例如 `/home/wy/code/chrome/o-maid/extension`）；
   - **私有密钥文件 (Private key file)**：
     - **如果是首次打包**：留空无需选择，直接点击「打包扩展程序」；
     - **如果是后续版本更新**：**必须**选择上一次打包时生成的 `.pem` 密钥文件，否则 Chrome 会认为这是两个不同的插件，导致旧数据无法继承且无法覆盖安装！
5. 打包成功后，Chrome 会在 `extension` 的上级目录生成两个文件：
   - `extension.crx`：插件安装包文件；
   - `extension.pem`：**核心密钥私钥（请务必妥善保存并备份，严禁丢失或泄露）**。

#### 步骤 3：分发与安装给同事
- **同事安装方法**：
  1. 打开 `chrome://extensions/` 页面，开启右上角的「开发者模式」；
  2. 将 `extension.crx` 文件直接**拖拽**进该页面；
  3. 页面弹出“添加「页面元素助手」吗？”，点击 **「添加扩展程序」** 即可完成安装。

---

### 2.2 方式 B：企业组策略（GPO/注册表）统一静默推送（IT 管理员批量部署）
对于配置了 Windows 域控或集中管理的企业电脑，员工无需手动操作，IT 管理员可通过组策略批量强制安装：
1. 将 `.crx` 安装包部署到企业内部文件服务器或内网 HTTP 服务器；
2. 在 Windows 组策略中配置 Chrome 策略：
   `Software\Policies\Google\Chrome\ExtensionInstallForcelist`；
3. 添加一条规则：`<插件ID>;http://内网服务器/extension_update.xml`；
4. 员工电脑在开机或刷新组策略后，Chrome 会自动在后台静默安装该插件。

## 三、途径二：Chrome 网上应用店 (Chrome Web Store) 官方公开发布

### 3.1 账号注册与资质准备
1. **Google 账号**：准备一个正常的 Google 账号；
2. **开发者入驻**：访问 [Chrome 开发者信息中心 (Developer Dashboard)](https://chrome.google.com/webstore/devconsole/)；
3. **缴纳注册费**：按照提示支付 **一次性 $5 美元** 的注册费用（需使用支持 Visa / MasterCard 等国际支付的双币信用卡）。

---

### 3.2 发布物料与素材清单 (Checklist)

在提交审核前，必须准备好以下物料：

#### 1. 图标资产 (Icons)
在 `extension/` 目录下放置以下尺寸的 PNG 图标并在 `manifest.json` 中声明：
- `icon16.png`：16 × 16 像素（浏览器标签页与卡片微标）
- `icon48.png`：48 × 48 像素（扩展管理页展示）
- `icon128.png`：128 × 128 像素（商店展示与安装弹窗）

#### 2. 商店宣传截屏 (Screenshots)
- **要求**：至少提供 **1 张** 高清截图，展示插件在真实网页（如 OA、业务系统）中的使用场景；
- **尺寸规范**：必须精准为 **1280 × 800** 像素或 **640 × 400** 像素（PNG 格式）；
- **建议内容**：
  - 图 1：右侧面板展开与规则管理列表界面；
  - 图 2：目标元素悬停柔光高亮与提示气泡停靠效果；
  - 图 3：引导任务全屏聚焦与步骤跳转效果。

#### 3. 隐私权政策与权限理由声明 (Privacy Practices)
- **隐私权政策链接 (Privacy Policy URL)**：
  - 官方硬性要求提供公开的隐私政策网页（可使用 GitHub Pages 托管一个单页 Markdown/HTML）；
  - 声明：*本扩展所记录的提示文案与选择器均保存在本地存储或用户自主配置的云端，插件绝不收集任何个人敏感信息、绝不出售用户数据*。
- **权限合理性说明（Justification）**：
  - `storage`：用于持久化保存用户在本地创建的悬停提示与引导任务规则；
  - `activeTab` / `scripting`：用于响应用户操作，在当前活动网页中定位 DOM 元素并展示交互高亮与引导气泡；
  - `webNavigation`：用于在跨页面引导流程中识别目标网页并自动恢复引导步骤。

---

### 3.3 打包 ZIP 文件与上传提审

#### 步骤 1：本地压缩打包
> [!IMPORTANT]
> **切勿直接压缩外层文件夹！**
> 必须进入 `extension/` 文件夹内部，选中所有文件进行打包，确保 `manifest.json` 位于 zip 文件的根路径！

- **Linux / Mac 终端快速打包命令**：
  ```bash
  cd /home/wy/code/chrome/o-maid/extension
  zip -r ../o-maid-v1.0.zip ./* -x "*.git*"
  ```

#### 步骤 2：上传到开发者控制台
1. 登录 [Chrome Web Store 开发者后台](https://chrome.google.com/webstore/devconsole/)；
2. 点击右上角 **「+ 新建项目 (New Item)」**；
3. 上传生成的 `o-maid-v1.0.zip`；
4. 填写基本资料：
   - **名称**：页面元素助手 (O-Maid)
   - **简短摘要**：网页元素精准标注、悬停提示与自动化业务操作引导助手。
   - **详细说明**：详细列举悬停提示、引导编排、云端协作等核心能力；
   - **类别**：选择 `生产力工具 (Productivity)`；
   - **语言**：中文（简体）；
5. 上传准备好的截图和商店宣传图；
6. 完善“隐私权”标签页下的权限理由并勾选合规复选框；
7. 点击 **「提交审核 (Submit for Review)」**。

#### 步骤 3：审核与上线
- Google 自动化测试系统会进行静态安全扫描；
- 审核团队人工复核权限使用情况，周期通常为 **24 ~ 72 小时**；
- 审核通过后，状态自动变为 **「已发布」**，插件获得专属的商店直达链接，全球任何 Chrome 用户均可直接安装。

## 四、后续版本迭代与更新规范

1. **修改版本号**：在 `extension/manifest.json` 中递增 `version`（例如从 `1.0` 改为 `1.1`）；
2. **内部私有更新**：
   - 使用 Chrome「打包扩展程序」，**载入原先的 `.pem` 私钥**重新打包为新的 `.crx`；
   - 分发新包，用户拖入浏览器即可无缝覆盖更新，原有数据完整保留。
3. **商店公开更新**：
   - 重新打包 ZIP 文件，在开发者控制台点击「上传新版本」并提交审核；
   - 审核通过后，全网已安装用户的 Chrome 浏览器会在 24 小时内自动在后台静默更新为最新版。
