# 高亮跟随功能调试步骤

## 🔍 问题：高亮跟随功能没有生效

### ✅ 请按以下步骤逐步排查

## 步骤 1: 重新加载扩展（最重要！）

```
1. 打开 Chrome 浏览器
2. 访问 chrome://extensions/
3. 找到 "O-Maid" 或 "页面元素助手"
4. 点击刷新图标 🔄（或者先关闭再重新加载）
```

**为什么重要**：代码修改后必须重新加载扩展才能生效！

---

## 步骤 2: 打开测试页面

```
1. 在项目目录中找到 test-highlight.html
2. 用 Chrome 浏览器打开这个文件
   或者打开任意网页（如 https://www.baidu.com）
```

---

## 步骤 3: 打开开发者工具

```
1. 按 F12 键（或右键 → 检查）
2. 切换到 "Console" 标签
3. 确保没有过滤，能看到所有日志
```

---

## 步骤 4: 激活选择模式

```
1. 点击浏览器工具栏上的扩展图标
2. 面板应该出现在页面右侧
3. 点击面板上的 "+" 按钮
4. 选择 "悬停提示"
```

---

## 步骤 5: 检查控制台日志

**应该看到以下日志**：
```
O-Maid 插件已加载！
O-Maid: 开始选择模式 {type: 'hint'}
O-Maid: 已添加事件监听器
```

### 如果没有看到这些日志：

#### 可能原因 A: 扩展没有加载
**解决方法**：
1. 检查 chrome://extensions/ 中扩展是否启用
2. 查看是否有错误提示
3. 重新加载扩展

#### 可能原因 B: 内容脚本没有注入
**解决方法**：
1. 刷新网页（F5）
2. 检查 manifest.json 中的 content_scripts 配置
3. 查看控制台是否有加载错误

---

## 步骤 6: 测试鼠标移动

```
1. 将鼠标移动到页面上的任意元素（如按钮、文本、图片等）
2. 观察控制台
3. 观察页面
```

**应该看到**：
- 控制台显示：`O-Maid: 创建高亮元素`（第一次）
- 控制台显示：`O-Maid: 高亮元素已添加到 body`
- 页面上出现蓝色高亮框跟随鼠标

### 如果看到日志但没有高亮框：

#### 调试方法 1: 检查高亮元素是否存在
在控制台运行：
```javascript
const highlight = document.getElementById('o-maid-selection-highlight');
console.log('高亮元素:', highlight);
console.log('高亮样式:', highlight ? highlight.style.cssText : '不存在');
```

#### 调试方法 2: 手动创建测试高亮
在控制台运行：
```javascript
// 创建一个红色测试高亮
const testHighlight = document.createElement('div');
testHighlight.style.position = 'absolute';
testHighlight.style.backgroundColor = 'rgba(255, 0, 0, 0.3)';
testHighlight.style.border = '2px solid red';
testHighlight.style.zIndex = '2147483647';
testHighlight.style.pointerEvents = 'none';
testHighlight.style.width = '200px';
testHighlight.style.height = '100px';
testHighlight.style.top = '100px';
testHighlight.style.left = '100px';
document.body.appendChild(testHighlight);
console.log('测试高亮已创建，应该在页面左上角看到红色方框');
```

如果看到红色方框，说明高亮元素可以正常显示，问题在于事件监听器。

#### 调试方法 3: 检查事件监听器
在控制台运行：
```javascript
// 检查 mouseover 事件监听器
const listeners = getEventListeners(document);
console.log('mouseover 监听器:', listeners.mouseover);
```

## 步骤 7: 常见问题排查

### 问题 A: 控制台显示 "O-Maid: 忽略面板元素"
**原因**: 鼠标移动到了面板上
**解决**: 将鼠标移动到页面的其他元素上

### 问题 B: 高亮框位置不对
**原因**: 可能是滚动位置计算问题
**解决**: 
1. 滚动到页面顶部测试
2. 检查控制台的位置日志

### 问题 C: 高亮框不跟随鼠标
**原因**: 事件监听器可能没有正确添加
**解决**:
1. 重新点击 "+" → "悬停提示"
2. 检查控制台是否显示 "已添加事件监听器"

### 问题 D: 点击元素后没有进入编辑界面
**原因**: 点击事件处理可能有问题
**解决**:
1. 查看控制台是否有错误
2. 确保点击的是页面元素，不是面板
