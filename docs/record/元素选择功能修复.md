# 元素选择功能修复说明

## 🐛 问题描述

用户点击"添加悬停提示"时，没有出现高亮跟随和元素选择功能。

## 🔍 问题分析

原来的代码流程：
1. UI 调用 `startSelectionMode()`
2. `startSelectionMode()` 只是广播消息到 background
3. background 再广播回所有页面
4. content.js 接收消息后才添加事件监听器

**问题**：这个流程太复杂，而且可能存在时序问题，导致事件监听器没有及时添加。

## ✅ 修复方案

### 修改的文件
`modules/element-selector.js`

### 修改内容

#### 1. `startSelectionMode()` - 直接添加事件监听器

```javascript
export function startSelectionMode(context, callback) {
    selectionContext = context;
    selectionCallback = callback;

    // ✅ 直接在本地添加事件监听器
    document.addEventListener('mouseover', highlightElementForSelection);
    document.addEventListener('click', selectElementForAction, { capture: true });

    // 同时广播到所有 frame 开始监听
    broadcastStartSelection();
}
```

**改进**：
- 不再依赖消息广播回调
- 立即在当前页面添加事件监听器
- 同时广播到其他 iframe（如果有的话）

#### 2. `stopSelectionMode()` - 添加广播

```javascript
export function stopSelectionMode() {
    // 本地清理
    document.removeEventListener('mouseover', highlightElementForSelection);
    document.removeEventListener('click', selectElementForAction, { capture: true });

    if (selectionHighlight) {
        selectionHighlight.remove();
        selectionHighlight = null;
    }

    selectionContext = null;
    selectionCallback = null;

    // ✅ 广播到所有 frame 停止选择模式
    broadcastStopSelection();
}
```

**改进**：
- 确保所有 frame 都停止选择模式

#### 3. `selectElementForAction()` - 修复逻辑顺序

```javascript
export function selectElementForAction(e) {
    e.preventDefault();
    e.stopPropagation();

    const selector = generateSelector(e.target);
    
    // ✅ 保存当前的上下文和回调（因为 stopSelectionMode 会清空它们）
    const savedContext = selectionContext;
    const savedCallback = selectionCallback;

    // 停止选择模式（会自动广播到所有 frame）
    stopSelectionMode();

    // 如果在 iframe 中，发送选择到 background 转发到顶层 frame
    if (window.self !== window.top) {
        elementSelectedInFrame(selector, window.location.href);
    } else {
        // ✅ 使用保存的上下文和回调处理选择
        if (savedCallback && savedContext) {
            savedCallback(selector, window.location.href, savedContext);
        }
    }
}
```

**改进**：
- 先保存上下文和回调
- 再停止选择模式
- 最后使用保存的值处理选择
- 避免了上下文被清空的问题

## 🎯 修复后的流程

### 添加悬停提示流程

1. 用户点击"悬停提示"按钮
2. `switchToView('edit-hint')` 被调用
3. `startSelectionMode({ type: 'hint' }, handleElementSelection)` 被调用
4. **立即**添加 `mouseover` 和 `click` 事件监听器
5. 用户移动鼠标 → 元素高亮显示 ✅
6. 用户点击元素 → 选择完成，显示编辑界面 ✅

### 关键改进

- ✅ **立即响应**：不再依赖消息传递，事件监听器立即添加
- ✅ **高亮跟随**：`mouseover` 事件立即生效
- ✅ **正确选择**：保存上下文避免被清空
- ✅ **跨 frame 支持**：仍然支持 iframe 中的元素选择
