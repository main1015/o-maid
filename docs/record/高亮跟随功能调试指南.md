# 高亮跟随功能调试指南

## 🐛 问题：高亮跟随功能没有生效

### ✅ 最新改进（2025-12-18）

我已经对代码进行了以下改进：

#### 1. **忽略面板元素**
```javascript
// 忽略面板元素和 iframe
if (e.target.tagName === 'IFRAME' || 
    e.target.closest('#o-maid-panel') || 
    e.target.id === 'o-maid-panel') {
    // 隐藏高亮
    return;
}
```

**改进点**：
- 鼠标移动到面板上时不会显示高亮
- 避免选择面板元素

#### 2. **提高 z-index**
```javascript
selectionHighlight.style.zIndex = '2147483647'; // 最高 z-index
```

**改进点**：
- 确保高亮元素在所有元素之上
- 面板的 z-index 是 2147483646，高亮是 2147483647

#### 3. **添加调试日志**
```javascript
console.log('O-Maid: 开始选择模式', context);
console.log('O-Maid: 已添加事件监听器');
console.log('O-Maid: 创建高亮元素');
```

**用途**：
- 可以在控制台查看功能是否正常执行
- 帮助定位问题

#### 4. **改进高亮样式**
```javascript
selectionHighlight.style.backgroundColor = 'rgba(0, 123, 255, 0.3)';
selectionHighlight.style.border = '2px solid #007bff';
selectionHighlight.style.boxSizing = 'border-box';
```

**改进点**：
- 更明显的边框（2px）
- 使用 box-sizing 避免尺寸计算问题

## 🔍 故障排查

### 问题 1: 没有看到控制台日志

**可能原因**：
- 扩展没有重新加载
- 内容脚本没有注入

**解决方法**：
1. 重新加载扩展
2. 刷新网页
3. 检查 manifest.json 中的 content_scripts 配置

### 问题 2: 看到日志但没有高亮

**可能原因**：
- 高亮元素被其他元素遮挡
- CSS 样式问题

**解决方法**：
1. 在控制台运行：
```javascript
document.getElementById('o-maid-selection-highlight')
```
2. 如果返回 null，说明高亮元素没有创建
3. 如果返回元素，检查其样式：
```javascript
const highlight = document.getElementById('o-maid-selection-highlight');
console.log(highlight.style.zIndex);
console.log(highlight.style.display);
```

### 问题 3: 高亮不跟随鼠标

**可能原因**：
- 事件监听器没有添加
- 事件被其他代码阻止

**解决方法**：
1. 在控制台运行：
```javascript
// 手动触发一次高亮测试
const testEvent = new MouseEvent('mouseover', {
    bubbles: true,
    cancelable: true,
    view: window
});
document.body.dispatchEvent(testEvent);
```

### 问题 4: 点击后没有进入编辑界面

**可能原因**：
- 选择器生成失败
- 回调函数没有执行

**解决方法**：
1. 查看控制台是否有错误
2. 检查 `handleElementSelection` 是否被调用
