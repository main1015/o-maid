📡 RESTful API 接口参考
POST /api/auth/register
用户注册账号。入参: { username, password }
POST /api/auth/login
用户登录换取 JWT Token。入参: { username, password }
GET /api/guides?domain={domain}
按域名拉取引导任务（若省略 domain 参数则拉取全部）。
POST /api/guides
发布或录入引导任务。支持传入 { name, startUrl, domain, steps, authorId }。
DELETE /api/guides/:id
删除指定的云端引导任务。
GET /api/hints?domain={domain}
按域名拉取特定页面的悬停提示列表。
POST /api/hints
发布或录入悬停提示。支持传入 { text, url, domain, selector, authorId }。
DELETE /api/hints/:id
删除指定的云端悬停提示。
