🔐 用户认证与权限体系 (/api/auth)

POST /api/auth/register 公开 / 管理员
用户注册。系统首个用户自动设定为超级管理员 (admin)，普通注册默认为 user。入参: { username, password, [role] }
POST /api/auth/login 公开
用户登录换取 JWT Token 与身份信息。入参: { username, password }
GET /api/auth/me 已登录
获取当前登录用户信息、归属角色 (admin / user) 与登录有效性。
PUT /api/auth/users/:id/role 仅管理员
调整指定用户的系统角色。入参: { role: "admin" | "user" }
POST /api/auth/users/:id/reset-password 仅管理员
管理员重置指定用户的登录密码。入参: { newPassword }
DELETE /api/auth/users/:id 仅管理员
删除指定用户账号（禁止删除本人当前登录账号）。

🗺️ 业务引导任务管理 (/api/guides)

GET /api/guides?domain={domain} 插件专用 / 可选鉴权
Chrome 插件专用：按当前访问域名拉取审核通过的引导任务（若携带 Token，创作者可见自己创建的待审核项）。
GET /api/guides/all[?status=pending] 可选鉴权
全网大厅 / 控制台列表：获取全量引导任务。管理员可见全状态，普通创作者可见已发布+本人作品，匿名仅见已发布。
GET /api/guides/:id 可选鉴权
查询单条引导任务的详细步骤列表与元数据信息（待审核项受权限隔离保护）。
POST /api/guides 已登录
发布或录入引导任务。普通用户发布默认进入 pending 待审核，管理员直接 approved 免审。支持传入 { name, startUrl, domain, steps, [authorId] }。
POST /api/guides/:id/audit 仅管理员
管理员审核引导任务。入参: { status: "approved" | "rejected" | "pending" }，通过后全网公开。
POST /api/guides/:id/download 公开
Chrome 插件下载引导任务时上报，热度/下载计数自增 +1。
DELETE /api/guides/:id 数据作者 / 管理员
删除指定的云端引导任务（仅管理员或该任务的原作者允许删除）。

💡 DOM 悬停提示管理 (/api/hints)

GET /api/hints?domain={domain} 插件专用 / 可选鉴权
Chrome 插件专用：按当前访问域名拉取已审核通过的悬停提示，注入到对应页面 DOM 元素。
GET /api/hints/all[?status=pending] 可选鉴权
全网大厅 / 控制台列表：获取全量悬停提示列表（支持状态过滤与创作者可见性隔离）。
GET /api/hints/:id 可选鉴权
查询单条悬停提示详情（包含提示文案、CSS 选择器路径及作者信息）。
POST /api/hints 已登录
发布或录入悬停提示。普通用户发布默认进入 pending 待审核，管理员直接 approved 免审。支持传入 { text, url, domain, selector, [authorId] }。
POST /api/hints/:id/audit 仅管理员
管理员审核悬停提示。入参: { status: "approved" | "rejected" | "pending" }，通过后全网公开。
POST /api/hints/:id/download 公开
Chrome 插件下载悬停提示时上报，热度/下载计数自增 +1。
DELETE /api/hints/:id 数据作者 / 管理员
删除指定的云端悬停提示（仅管理员或该提示的原作者允许删除）。

📊 数据大盘与监控统计 (/api/stats)

GET /api/stats/overview 已登录
获取控制台核心指标统计：用户总数、任务数、提示数、累计下载量、待审核总数 (pendingTotal) 及最新发布动态。
GET /api/stats/users 仅管理员
获取系统中所有已注册创作者列表、当前角色与各自作品发布统计数据。
